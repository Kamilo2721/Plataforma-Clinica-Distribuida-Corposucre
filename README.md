# Plataforma Clínica Distribuida HL7 FHIR - UAJS

Este repositorio contiene el ecosistema clínico distribuido para Sistemas Distribuidos con el profesor Jaider Reyes.

## 🗺️ Arquitectura
3 nodos regionales (Sincelejo, Medellín y Bogotá) orquestados con Docker, Hapi FHIR y un API Gateway en Python Flask con Failover.

## 🚀 Despliegue
1. docker compose up -d
2. python app.py
3. Abrir index.html

## 📁 Contenido
Incluye app.py, docker-compose.yml, index.html, documento.pdf, evidencias y el video del proyecto.
